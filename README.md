# Hi, I'm Jason

### Web Developer • Maker • Hardware Builder

I'm a developer and maker from Ireland interested in building useful things across **web development, electronics, hardware, CAD, automation, and engineering**.

I enjoy taking ideas from a rough concept all the way to something that actually works, whether that's a website, PCB, 3D-printed mechanism, CNC machine, or random hardware project.
